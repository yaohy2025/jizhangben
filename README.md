# 随手账 · 记账本

> 一个纯前端、单文件的个人记账 Web 应用。无需安装、无需联网、无需后端，双击即可使用。

应用标题：`随手账 · 杨倩倩记账本`（LEDGER），采用移动端优先的「账本」视觉风格，绿色为主色调，支持桌面与手机浏览器。

---

## ✨ 功能特性

- **📝 记一笔**：支持「支出 / 收入」切换，内置常用分类（餐饮、交通、购物、居住、娱乐、医疗、学习、人情、通讯、其他等），可填写自定义名称、备注与日期。桌面端带自定义数字键盘，手机端自动切换为系统键盘。
- **🧾 明细**：按「月」查看账单，按「日」分组展示，顶部小票式汇总本月收入 / 支出 / 结余；支持**关键词搜索**（名称、备注、分类）以及快捷搜索标签。点击任意记录可**编辑或删除**。
- **📊 统计**：支持「本周 / 本月 / 本年 / 自定义」时间范围；包含总支出、总收入、结余、日均支出、笔数、环比上一周期；支出分类环形图 + 图例、TOP3 消费榜、收支趋势柱状图（可切换支出 / 收入）。
- **🎯 预算**：设置「本月总预算」与「分类预算」，带进度条与超支提醒（接近 / 超支变色）。
- **💾 数据安全**：支持导出 CSV、导出 JSON 备份、导入 CSV/JSON（覆盖或合并去重）、一键清空所有数据。

---

## 🚀 快速开始

1. 本目录下的 `记账本.html` 即为应用本体。
2. **直接使用**：双击 `记账本.html`（或拖入浏览器）即可打开，无需任何安装或服务器。
3. **手机使用**：将 `记账本.html` 通过聊天 / 网盘传到手机，用浏览器打开即可（建议「添加到主屏幕」当 App 用）。

> 首次打开无任何数据，直接在「记账」页记下第一笔即可。

## 📖 使用说明

底部四个标签页：

| 标签 | 说明 |
| --- | --- |
| ✍️ 记账 | 选择收/支、输入金额、选分类、填名称/备注/日期，点「记一笔」。点击已有记录可进入编辑态。 |
| 🧾 明细 | 查看当月收支明细，支持搜索与快捷标签；顶部齿轮菜单可导出/备份/导入/清空。 |
| 📊 统计 | 选择时间范围查看支出结构、消费排行与收支趋势。 |
| 🎯 预算 | 设置总预算与分类预算，实时查看使用进度。 |

顶部可切换「年 / 月」查看不同月份；右上角 ⚙ 打开数据管理菜单。

## 💾 数据说明

- **存储位置**：所有记账数据与预算保存在浏览器的 `localStorage`（键名 `ledger_records`、`ledger_budgets`）。
- **隐私**：数据只存在你自己的设备上，不经过任何服务器。
- **备份建议**：定期通过 ⚙ →「💾 备份 JSON」导出备份文件，换设备或清理浏览器前务必先备份。

### 导入 / 导出格式

- **导出 CSV**：列顺序为 `日期, 类型, 分类, 名称, 金额, 备注`（带 UTF-8 BOM，Excel 直接打开不乱码）。
- **导出 JSON**：完整备份 `{ version, exportedAt, records, budgets }`，可完整恢复（含记录 ID、创建时间与预算）。
- **导入**：自动识别 CSV / JSON。导入时弹出选择 ——
  - 「确定」= **覆盖**现有全部数据；
  - 「取消」= **合并**到现有数据（按日期/类型/分类/金额/名称/备注自动去重）。

## ⚠️ 注意事项

1. **换设备 / 清缓存会丢数据**：`localStorage` 跟随浏览器与设备。清理浏览器数据、换浏览器、换手机都会丢失记录，请务必提前备份 JSON。
2. **无云端同步**：当前版本不支持多设备自动同步，跨设备需手动导出 / 导入。
3. **离线字体**：界面字体来自 Google Fonts，无网络时自动回退到系统字体，不影响功能。
4. **金额精度**：金额以「元」为单位，最多 2 位小数；统计与结余按实际数值计算。
