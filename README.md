# 随手账 · 记账本

一款纯前端、单文件的个人记账应用，无需安装、无需服务器，双击即可使用。数据保存在浏览器本地，安全离线。

## 功能特性

### ✍️ 记一笔
- 支出 / 收入一键切换，10 类支出（餐饮、交通、购物、居住、娱乐、医疗、学习、人情、通讯、其他）+ 6 类收入（工资、奖金、投资、兼职、报销、其他）
- 自定义数字键盘 + 支持系统键盘直接输入，金额自动校验（整数 7 位、小数 2 位）
- 每笔账可添加自定义名称（如"星巴克拿铁"）和备注
- 日期选择器 + "今天"快捷按钮
- 点击任意明细可重新编辑，支持删除并一键撤销

### 🧾 明细
- 关键词搜索（匹配名称、备注、分类），支持快捷标签、关键词高亮
- 收入 / 支出独立筛选
- 按日期分组的账单列表，附小票样式的月度汇总（收入合计 / 支出合计 / 本月结余）

### 📊 统计
- 统计区间：本周 / 本月 / 本年 / 自定义日期区间
- 总支出、总收入、结余、日均支出、记录笔数，以及与上一周期的环比
- 支出分类环形图 + Top3 排行 + 图例占比
- 收支趋势柱状图（按日 / 按周 / 按月自动分桶，支持切换支出 / 收入）

### 🎯 预算
- 月度总预算，进度条实时显示使用比例（70% 预警、90% 超支变色）
- 10 个分类独立预算，逐项显示已用 / 剩余 / 超支

### 💾 数据管理
- 导出 CSV（可用 Excel 打开）
- 备份 JSON（完整保留记录与预算，推荐定期备份）
- 导入数据：自动识别 CSV / JSON，支持**覆盖**或**合并去重**两种模式
- 一键下载导入模板
- 距离上次备份超过 7 天自动提醒

### 🎨 其他
- 深色 / 浅色模式（跟随系统偏好，可手动切换并记忆）
- 移动端适配：触屏设备自动改用系统键盘，支持 PWA 添加到主屏幕
- 月份选择弹窗，快速跳转到任意有记录的月份

## 快速开始

1. 用浏览器（Chrome / Edge / Safari 等）打开 `记账本.html`
2. 在"记账"页选择类型与分类，输入金额，点击「记一笔」
3. 所有数据自动保存在浏览器本地（localStorage），关闭页面不丢失

> 💡 建议：定期使用「⚙ → 备份 JSON」导出备份，以防浏览器清理本地数据。

## 使用提示

- **修改记录**：在"明细"页点击任意一条记录即可进入编辑状态，可修改金额、分类、名称、日期、备注，或删除（5 秒内可撤销）
- **查看其他月份**：点击顶部月份（如"2026年8月"）可打开月份选择弹窗；或用左右箭头逐月切换
- **导入数据格式**：可从「⚙ → 下载导入模板」获取 CSV 模板，列顺序为 `日期,类型,分类,名称,金额,备注`；JSON 需为备份格式 `{"records":[...],"budgets":{...}}` 或纯数组

## 技术说明

- **技术栈**：原生 HTML + CSS + JavaScript，零依赖、零构建，单文件约 1100 行
- **数据存储**：`localStorage`，键名 `ledger_records`（记账数据）、`ledger_budgets`（预算）、`ledger_theme`（主题）
- **安全设计**：所有渲染内容经过 HTML 转义，杜绝 XSS；导入数据严格校验
- **兼容性**：支持现代桌面与移动浏览器，移动端为移动优先设计（最大宽度 430px）
- 仅外部资源为 Google Fonts（网络字体），离线时自动回退到系统字体，不影响使用
